# Ludo 2D Game

## Overview

This is a **2D Ludo game** developed for Android using **Unity 6**.

## Features

-   2D graphics\
-   Dice system\
-   Token control\
-   Theme support\
-   Music and SFX\
-   In-app purchases (Poolakey)\
-   Player profile\
-   RTL text support (Persian)

## How to Run

1.  Open the project with Unity 6\
2.  Load the `FirstPage` scene\
3.  Press Play
